# Hi, I'm Abhishek 👋

I build web apps by sketching first: a quick, rough version of an idea that
exists early enough to see, test and improve. I work the same way in code.
Start small, get something running, then refine it.

## What I do

- Turn ideas into working web apps
- Experiment with AI-powered tools
- Learn by building, then polish what works

## How I work

Sketch the idea → build a rough version → test it → refine → ship.
